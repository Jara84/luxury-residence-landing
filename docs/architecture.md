# Residencia El Cerro

## Objetivo

Construir una experiencia web premium para la comercialización de un apartamento de lujo ubicado en el Cerro Nutibara (Medellín).

La aplicación debe transmitir exclusividad, confianza y calidad desde los primeros segundos de navegación.
